MIT-licensed upstream subtrees include:

  src/doc/         Document Library
  src/render/      Render Library
  src/dio/         Document I/O Library
  src/ui/          UI widget framework
  src/observable/  Signal/slot library
  src/undo/        Generic undo history library
  src/fixmath/     Fixed-point math (Allegro heritage)
  src/flic/        FLI/FLC file loader/saver
  src/cfg/         INI-file load/save library
  src/net/         HTTP request library
  src/desktop/     Desktop integration
  src/gen/         XML-to-C++ code generator
  src/steam/       Steam API wrapper

upstream Git repositories during the Aseprite build, are also MIT.
