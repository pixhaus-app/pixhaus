---
title: "Audio-driven timing"
description: "Beat detection and lip-sync timing from audio."
---

Analyzes an audio clip and places frame timing markers at beat positions (music mode) or syllable boundaries (lip-sync mode). Lip-sync mode also generates a rough mouth-shape layer.

Invoke via `AI > Audio-driven timing`. Drop an MP3, WAV, or OGG file into the input.

**Backend:** Classical audio analysis for beat detection; VLM for lip-sync intent.
