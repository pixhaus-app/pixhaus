---
title: "Variant"
description: "Generate palette swaps, equipment overlays, and expression sets."
---

Generates visual variants of a base sprite: palette swaps, equipment overlays, or expression changes.

Invoke via `AI > Variant`. Choose the variant type and describe the change. Results appear as new derived layers.

**Backend:** Image editing with reference conditioning. Palette-swap mode uses classical index substitution with AI refinement for edge cases.
