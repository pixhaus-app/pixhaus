---
title: "Conversational editing"
description: "Natural language multi-step editor commands."
---

Describe what you want to change in plain language. The AI plans a command sequence, shows you the plan, then executes it on confirmation. All steps commit as a single grouped undo entry.

Invoke via `AI > Conversational editing` or `Ctrl+Shift+K`.

Example: `Make this enemy look angrier, add a scar over the left eye, slow the walk to 8fps`

**Backend:** Vision-language model with tool-use capability. Simple, specific requests work best.
