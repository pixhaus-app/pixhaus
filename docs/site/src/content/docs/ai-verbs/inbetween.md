---
title: "Inbetween"
description: "Generate intermediate frames between two key frames, palette-locked."
---

Generates one or more intermediate frames between two selected key frames. Output snaps to the project palette.

Invoke via `AI > Inbetween` or the command palette. Select two key frames in the timeline, set the number of in-between frames, and run. Accept or reject the preview.

**Backend:** Image generation with palette conditioning.
