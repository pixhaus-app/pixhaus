---
title: "Auto-mesh deformation"
description: "No-bones deformation rig from a single sprite."
---

Derives a Live2D-style mesh deformation rig from a single sprite without explicit bones. The sprite gains parameter sliders for secondary motion (breathing, hit reactions, squash/stretch) without frame-by-frame redrawing.

Invoke via `AI > Auto-mesh deformation`. Works best on characters with clearly segmented regions.

**Backend:** Segmentation and view synthesis.

**Note:** This verb is a stretch goal in the initial release. Check release notes for completion status.
