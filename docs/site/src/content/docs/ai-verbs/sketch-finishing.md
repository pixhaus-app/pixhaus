---
title: "Sketch finishing"
description: "Finish rough sketches in project style."
---

Refines rough gesture sketches and silhouettes into finished sprites in your project visual style.

Draw rough shapes on a new layer above the base. Select the sketch layer. Invoke via `AI > Sketch finishing`. The verb generates a finished sprite on a new layer, reviewed frame by frame.

**Backend:** Image editing with project style reference (style LoRA if trained, otherwise the most recent frames as conditioning).
