## Phase 1 — Correctness, consistency, and doc (commit 1)

### A — Real bugs

**A1. `compute_next_id` skips Tilemap and Reference content** (`app/src/commands/project.rs:188`)

The match arms `EntityContent::Tilemap | EntityContent::Reference => {}` are empty. Fill them:

- `Tilemap { scene }` — scan `scene.layers[].id` (`LayerId`). `scene.tilesets[].tileset_entity_id` is an `EntityId` already covered by the outer loop, no rescan needed.
- `Reference { sheet }` — scan `sheet.canonical.id` (`SheetVariantId`), every `sheet.history[].id`. `PromptResult::Variant(sid)` ids are subsets of `history` ids in normal flow; verify by reading `core/src/project/library.rs` to confirm the data model. If a `PromptResult` can carry a sheet variant id not in `history`, scan those too.

**A2. `compute_next_id` skips `LayerKind::Reference` PixelBufferId** (`app/src/commands/project.rs:159`)

Inside the per-sprite layer loop, add:
```rust
if let LayerKind::Reference { image, .. } = &layer.kind {
    max = max.max(image.get());
}
```
`LayerKind::Tilemap { tileset }` references an existing tileset already covered by `sprite.tilesets[]`, so no rescan. Confirmed in `core/src/project/layer.rs`.

**A3. `library_delete_group` cascade leaves dangling `anchor_reference_id`** (`app/src/commands/library.rs:1098`)

After `entities.retain(|e| !to_delete.contains(&e.id))`, mirror the cleanup at line ~397 (in `library_delete_entity`): walk surviving entities, clear `anchor_reference_id` whose target is in `to_delete`. Bump `updated_at` on every entity whose anchor was cleared (combine with B4).

**A4. `library_create_entity` doesn't populate `EntityDefaults` for Custom entities** (`app/src/commands/library.rs:330`)

When `args.kind` is `EntityKind::Custom(_)`, the function builds initial sprites with `canvas` and `color_mode` from args, then stores `defaults: EntityDefaults::default()` — losing the canvas/color info. Subsequent `library_add_state` falls back to 16×16/RGBA. Fix:
```rust
defaults: if matches!(args.kind, EntityKind::Custom(_)) {
    EntityDefaults {
        canvas_size: Some(canvas),
        color_mode: Some(color_mode),
        default_palette_id: None,
        default_pivot: None,
        default_fps: None,
    }
} else {
    EntityDefaults::default()
},
```

## Phase 2 — Performance (commit 2)

**C1. `library_delete_group` cascade uses `Vec::contains`** (`library.rs:1079`)

Convert `to_delete: Vec<EntityId>` → `HashSet<EntityId>`. Three sites use it:
- `project.library.entities.retain(|e| !to_delete.contains(&e.id))`
- `to_delete.contains(&eid)` (active-target check)
- `project.library.ai.style_corpus.retain(|id| !to_delete.contains(id))`

All three benefit. Use `std::collections::HashSet`.

**C2. `library_search` precompute lowercased tag names** (`library.rs:1399`)

Before the entity loop, build:
```rust
let lc_tag_names: HashMap<TagId, String> = project
    .library
    .tags
    .iter()
    .map(|t| (t.id, t.name.to_lowercase()))
    .collect();
```

Per-entity scan becomes `O(tags_on_entity)` `HashMap::get` lookups instead of `O(tags_on_entity × project_tags)` linear scans. Also verify the query is lowercased once outside the loop, not per entity.

## Phase 3 — Test quality refactor (commit 3)

The current `library.rs::tests` (around line 1466+) mutate `Project` fields directly. The IPC commands could break (validation, NotFound paths, dirty/updated_at semantics) and tests still pass. Fix by extracting pure helpers.

### Pattern

```rust
// In library.rs, alongside the commands:
pub(crate) fn rename_entity_in_project(
    project: &mut Project,
    entity_id: EntityId,
    name: String,
    ts: i64,
) -> Result<(), AppCommandError> {
    if name.trim().is_empty() {
        return Err(AppCommandError::Validation { /* … */ });
    }
    let entity = project
        .library
        .entities
        .iter_mut()
        .find(|e| e.id == entity_id)
        .ok_or(AppCommandError::NotFound { /* … */ })?;
    entity.name = name;
    entity.updated_at = ts;
    Ok(())
}

#[tauri::command(async, rename_all = "snake_case")]
pub async fn library_rename_entity(
    entity_id: EntityId,
    name: String,
    state: State<'_, AppState>,
) -> CommandResult<()> {
    let mut doc = state.doc.write().await;
    let project = doc.project.as_mut().ok_or(AppCommandError::NoActiveProject)?;
    rename_entity_in_project(project, entity_id, name, now_secs())?;
    doc.dirty = true;
    Ok(())
}
```
