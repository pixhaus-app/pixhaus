# Pixaki

## Quick facts
- Vendor / maintainer: Luke Rizer (independent developer)
- License / pricing model: Commercial, in-app purchase
- Price point (current): Pixaki 4 Pro $27-$30 USD; Pixaki 4 Intro free (limited); upgrade from v3 $6 USD
- Platforms: iPad only (iOS 13.0+); Apple Vision OS 1.0+
- First released: Pixaki 3 (2016); Pixaki 4 (2021)
- Last meaningful update: Pixaki 4 (2021+); active maintenance
- Source available: No (proprietary)
- Primary use case: Premium pixel art and animation creation on iPad with Apple Pencil support

## Origin and purpose

Pixaki is a premium iPad pixel editor developed by solo developer Luke Rizer. Designed from the ground up for iPad with native Apple Pencil support, Pixaki emphasizes tactile, gesture-driven workflows unavailable on desktop. Pixaki 3 established the foundation; Pixaki 4 modernized the UI and added features. The premium pricing reflects iPad App Store distribution and solo development. The tool targets artists who prefer iPad creation workflows and seamless integration with iOS ecosystem. Professional support for export formats (Aseprite .ase, Photoshop .psd) positions it as a professional tool despite mobile constraints.

## Drawing and painting tools

Pencil, eraser, and brush tools with pressure sensitivity and brush dynamics. Round and square brush options. Matrix Dither brush with 13 dithering patterns for complex color mixing without expanded palettes. Custom brush library. Opacity and size controls. Undo/redo at unlimited depth (according to description, though device memory may impose practical limits). Pressure curve customization for Apple Pencil. Gesture controls for rapid tool switching and color selection. Anti-aliasing toggle. Drawing on iPad with Pencil is the primary workflow; touch interaction is minimal to avoid accidental marks.

## Pixel-specific features

Grid overlay with configurable spacing and snapping. Zoom levels from close pixel work to full-canvas view. Rotation and flip transformations. Tiled drawing mode for seamless patterns. Color picker (eyedropper) via tap-and-hold. Selection tools (rectangular, freehand, magic wand). Stroke and fill selections. Transform and warp tools. iPad-native gestures (pinch, two-finger pan) accelerate navigation. Apple Pencil double-tap for brush size/opacity adjustment. Squeeze gesture support (Apple Pencil 2). Pixel-perfect painting mode automatically prevents double pixels in line art, saving time.

## Color and palette workflow

Color picker with swatches. Custom palette creation and import. Color history. HSL and other color space pickers. Eyedropper with average color option. Foreground/background color swapping. Gradient fills. Pattern fills. RGB color mode. Palette editing and rearrangement. Palette library management. Color range selection.

## Layer system

Unlimited layers in Pixaki 4 Pro (3 layers in Intro version). Layer visibility toggling and locking. Layer opacity control. Merge and flatten operations. Layer groups for hierarchical organization. Layer blending modes (multiply, screen, overlay, etc.). Layer naming and organization. Transparency support in RGB and indexed modes. Layer effects may be supported (feature list varies by version).

## Animation features

Unlimited animation frames in Pro version (8 frames in Intro). Frame-based timeline. Adjustable frame duration per frame. Real-time animation playback within the editor. Onion skinning with adjustable opacity and range. Loop, ping-pong, and playback speed options. Frame duplication and deletion. Frame organization and naming. Animation preview is responsive on iPad hardware. The animation timeline is touch-optimized for iPad interaction.

## Export and import

PNG and JPEG export with transparency and quality options. GIF export for web sharing and social media. Animated PNG (APNG) export for advanced web animation. QuickTime movie export for video preview and documentation. Layered PSD export compatible with Photoshop, Pixelmator, and Procreate. Aseprite .ase import and export for cross-application workflows. PNG sequence import to populate frames. Image import (PNG, JPEG) as layers or frame backgrounds. PDF export for documentation. Clipboard import/export for rapid sharing.

## Scripting and extensibility

No scripting or plugin system. iPad app architecture limits extensibility. Customization relies on in-app settings and official feature updates. The solo developer approach means feature additions depend on user requests and developer priorities.

## Engine integration

Export formats (PNG, GIF, APNG, PSD) suit game engines and web workflows. Aseprite format compatibility enables seamless integration with Aseprite-based pipelines. PNG sequences export for frame-by-frame game engine import. No native engine plugins or integrations due to iOS app architecture limitations.

## Workflow strengths

iPad-native design optimizes for tablet touchscreen and Apple Pencil workflows. Pressure sensitivity and gesture controls are intuitive for artists accustomed to iPad drawing apps. Unlimited layers and frames in Pro version (within device memory). Pixel-perfect painting mode saves time on line art. Aseprite and PSD export compatibility bridges to desktop workflows. Premium quality and responsive performance on iPad hardware. Seamless iOS/iPadOS integration (iCloud save, document handling). Gesture controls (squeeze, double-tap) accelerate common operations. Apple Pencil 2 gesture support. The tactile workflow appeals to artists transitioning from paper to digital.

## Workflow gaps

iPad-only platform limits use for desktop-centric studios and educational institutions with Windows/macOS labs. Limited advanced features compared to desktop tools (no scripting, no plugins, no text tool). Layer group blend modes and advanced compositing may be constrained by iOS architecture. Touch gestures can cause accidental marks despite prevention measures. Export limitations compared to desktop tools (no video export, no advanced sprite sheet generation). Screen size constraints (even iPad Pro) limit real-time preview of full spritesheets. Onion skin color scheme may not be customizable. No multiplayer or collaboration features. Feature parity with Aseprite is incomplete. Ongoing iPad app store policy compliance and iOS updates may affect stability.

## Notable uses

Pixel artists working on iPad (concept artists, freelancers, hobbyists) use Pixaki for rapid iteration and portability. Game studios with iPad workflow integration (e.g., prototyping on-site) use Pixaki. Educators teaching pixel art on iPad in creative schools benefit from native iPad design. Remote artists prefer iPad workflow during travel or off-site work. Aseprite users maintain iPad workflow via Pixaki with PSD/Aseprite interchange. Character animators use Pixaki for animation frame creation on iPad.

## Pricing details

Pixaki 4 Pro costs $27-$30 USD on the App Store (exact price varies by region and App Store currency). Pixaki 4 Intro is available as a freemium version, limited to 160 x 160 px canvas, 3 layers, and 8 animation frames. Upgrading from Intro to Pro is approximately $6 USD in-app purchase. Pixaki 3 (legacy version) is still available but receives no updates. Upgrade from Pixaki 3 to version 4 is discounted (details vary, historically $6-$10 for existing users). No subscription model; one-time purchase. Created artwork has no commercial restrictions. Educational bulk licensing information is not advertised; individual educational pricing may be negotiable with the developer.
