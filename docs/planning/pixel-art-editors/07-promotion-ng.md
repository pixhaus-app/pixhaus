# Pro Motion NG

## Quick facts
- Vendor / maintainer: Cosmigo (independent developer)
- License / pricing model: Commercial, one-time purchase
- Price point (current): $24.99-$39.99 USD (varies by platform/sales)
- Platforms: Windows, macOS, Linux (via Electron/wrapper)
- First released: 1990s (Motion, Pro Motion; NG version ~2010)
- Last meaningful update: V8 release (date unspecified); active maintenance
- Source available: No (proprietary)
- Primary use case: Professional pixel art animation and tilemap editing for retro and modern game studios

## Origin and purpose

Pro Motion is a two-decade veteran of pixel art software, developed by Cosmigo. The "NG" (next generation) update modernized the interface while preserving the professional toolset accumulated over years of studio use. Adopted by Yacht Club Games, Wayforward, HalfBrick Studios, and other AAA indie studios, Pro Motion NG established a reputation as an industry standard for sprite animation. The tool balances retro game support (Sega, NES, SNES palette and resolution constraints) with modern workflow efficiency. Development is actively maintained with regular updates and studio feedback integration.

## Drawing and painting tools

Pencil, eraser, brush, line, rectangle, ellipse, and polygon tools. Customizable brush sizes, shapes, and opacity. Anti-aliasing toggle for pixel-perfect lines. Fill tool with color replacement options. Selection tools (rectangular, freehand, magic wand). Color exchange for batch color changes. Custom brush library creation. Drawing performance is optimized for rapid iteration. Drawing tools are professional-grade without unnecessary complexity.

## Pixel-specific features

Grid overlay with snapping and customizable spacing. Pixel-perfect drawing modes. Zoom levels from macro pixel work to spritesheet overview. Rotation and flip commands. Tiled drawing mode for seamless pattern and texture creation. Onion skinning for animation reference. Symmetry tools reduce work on bilateral designs. Resolution constraints for console emulation (NES, SNES, Sega resolutions and palette limitations). Color fidelity matching for retro platforms. Canvas sizing and composition.

## Color and palette workflow

Color swatches and palette management. Foreground/background color selection with quick swap. Palette import from images or manual creation. RGB and indexed color modes. Color range selection. Eyedropper tool. Palette export for game engine use. Gradient fills. Pattern-based fills. Palette animation via color cycling. Pro Motion NG supports palette constraints matching classic console limitations, allowing artists to create authentic retro art within technical specifications. This feature distinguishes it for retro game development.

## Layer system

Multiple layers with transparency. Layer visibility toggling and locking. Layer opacity control. Layer organization for complex sprites. Merging and flattening operations. Layer hierarchy management. The layer system supports traditional cel animation workflows where each cel is a frame/layer combination.

## Animation features

Cel animation focused on frame-by-frame sprite creation. Timeline displays frames and layers. Adjustable frame durations. Onion skinning with customizable range, opacity, and colors (forward/backward frames distinct). Real-time playback preview at specified frame rate. Loop and playback options (loop, ping-pong, single play). Multiple animation sequences within a single project. Animation playback is responsive and responsive to changes. Frame numbering and naming. The animation timeline is optimized for fluent cel animation workflows. In-app animation preview with speed control.

## Export and import

Animated GIF export with palette and dither options. PNG sprite sheet export with customizable layout and tile spacing. PNG image sequences (frame-by-frame) for external editing and compositing. AVI and video export for documentation and web preview. Aseprite import/export compatibility (limited, feature-dependent). Image import (PNG, BMP) to populate frames or create mockups. Tileset PNG import for tile editing. Palette export for external use. Export presets for rapid reproduction of settings. Batch export capabilities. Auto-optimization for export file size.

## Scripting and extensibility

Limited scripting support compared to Aseprite. Unknown current scripting capabilities in V8. Closed-source architecture limits community extensibility. Customization relies on developer roadmap and feature requests rather than user-created plugins.

## Engine integration

Pro Motion NG exports sprite sheets compatible with Unity, Unreal, Godot, and custom engines. PNG sprite sheet format is universal. GIF and video exports suit web preview. Tilemap export includes JSON or XML data for level editors. No native engine plugins, but export formats integrate smoothly into standard game pipelines. Tilemap editor integrates collision layers and auto-mapping features.

## Workflow strengths

Professional-grade animation tools with responsive onion skinning and playback. In-place tile modification with real-time propagation across tilesets reduces iteration cycles. Tilemap editor with auto-optimization and flexible export (JSON, binary, PNG). Palette constraints for console emulation support authentic retro art. Two-mode tile editing (pick/place vs. modify/create) separates asset creation from level building. Auto-mapping and collision layer support streamline level design. Studio adoption and industry reputation attract professionals. Proven history with AAA and indie releases. Export customization and presets accelerate production workflows. Responsive team and active development.

## Workflow gaps

Closed-source limits extensibility and community contributions. Scripting capabilities are unclear and likely limited. Documentation is adequate but not as comprehensive as open-source competitors. Smaller community than Aseprite means fewer tutorials and third-party tools. No non-destructive effects or advanced compositing. No text tool. Development pace depends on commercial viability; no guarantee of rapid feature additions. UI modernization lags contemporary standards aesthetically. No collaboration tools. Pricing may exceed hobbyist budgets compared to free alternatives.
