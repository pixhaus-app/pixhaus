## Origin and purpose

Pixilart is a dual-purpose platform: pixel art editor and social network. The browser-based editor is free and accessible without installation. Mobile apps extend reach to on-the-go creation. The social platform (profiles, galleries, forums, challenges) creates community engagement and discoverability. Monthly challenges and community events drive user retention. The model appeals to hobbyists, educators, and beginners seeking low-friction creation and social feedback. Pixilart differentiated itself from pure editors by embedding social discovery into the workflow, rather than treating it as post-hoc sharing.

## Drawing and painting tools

Pencil, eraser, brush, line, rectangle, ellipse tools. Customizable brush sizes. Fill tool with color replacement. Selection tools (rectangular, freehand). Color picker. Custom brushes may be supported. The drawing toolkit is straightforward, suitable for sprite and pixel art creation without steep learning curves. Tools are responsive on both web and mobile platforms.

## Pixel-specific features

Grid overlay with configurable spacing and snapping. Zoom levels for detail work and overview. Pixel-perfect line drawing. Tiled drawing mode for seamless patterns. Rotation and flip transformations. Stamp tool for incorporating pre-made snippets and custom sprites. Color picker and eyedropper. Mirror and symmetry tools may be supported. Canvas sizing and composition. Dithering patterns available (quantity unknown).

## Color and palette workflow

Foreground and background color selection with quick swap. Color history. Custom palette creation and import. Access to over 65,000 user-generated color palettes curated by the community. RGB color mode. Color picker with swatches. Eyedropper tool. Gradient fills. Pattern fills. Palette library for rapid switching between community palettes and custom sets. The palette sharing feature is unique to Pixilart; artists can publish palettes for community use.

## Layer system

Multiple layers with adjustable opacity and blending modes. Layer visibility toggling. Layer locking and organization. Merging and flattening operations. Layer opacity control. Blend modes enable advanced compositing (multiply, screen, overlay, etc.). Layer support enables complex sprite composition.

## Animation features

Multiple frames for GIF animation creation. Frame-based timeline with individual frame speed control (millisecond duration). Onion skinning with adjustable opacity for motion reference between frames. Unlimited frame count (upload performance may vary with size). Loop, ping-pong, and playback options. Real-time animation preview. Frame duplication and deletion. Animation workflow is streamlined for simple-to-moderate complexity animation. Web and mobile animation editors are feature-parity.

## Export and import

GIF export for animated pixel art sharing on social media and web. PNG image export with transparency. Sprite sheet export (functionality unclear; may be limited). PNG sequence export for frame-by-frame use. Animated PNG (APNG) export may be supported. Image import (PNG, JPEG) to populate layers or frames. GIF import to convert existing animations into Pixilart projects. SVG import/export (unclear support). Format compatibility with game engines varies; GIF and PNG are universal.

## Scripting and extensibility

No scripting or plugin system. Web app architecture limits extensibility. Community feature requests drive development roadmap. Closed-source proprietary model prevents user extensions.

## Engine integration

PNG and GIF exports are compatible with game engines (Unity, Godot, Phaser, custom engines). No direct engine integrations or plugins. Sprite sheet and frame sequence exports suit custom game pipelines. Web-based preview via GIF enables rapid iteration feedback.

## Workflow strengths

Social integration creates community discovery and engagement unavailable in pure editors. Monthly challenges and events drive motivation and skill sharing. Access to 65,000 community-created palettes accelerates color workflow. Free web and mobile editors remove barriers to entry. No installation required; works in any browser. Cross-platform consistency (web, iOS, Android). Real-time animation preview with frame-by-frame control. GIF export suitable for rapid web sharing. Community features (profiles, galleries, forums) provide feedback and learning opportunities. Beginner-friendly interface encourages new artists. Stamp tool enables rapid sprite assembly.

## Workflow gaps

Limited advanced features compared to Aseprite or Pixelorama (no text tool, no advanced brushes, no scripting). No tilemap or level editor. Animation capabilities are basic; complex frame-by-frame work would route to Aseprite. No non-destructive effects or advanced layer compositing. Sprite sheet export may be limited or unsupported. No offline editor for web version (requires internet). Mobile app UX may lag desktop for precision work. Community features imply data collection and privacy policies (relevant for institutional use). Performance on very large canvases unknown. Onion skin colors may not be customizable. No collaboration tools (real-time multiplayer editing). No version control or project history beyond browser storage.
