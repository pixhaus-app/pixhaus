# GraphicsGale

## Quick facts
- Vendor / maintainer: Original developer (Japanese, now open as freeware)
- License / pricing model: Freeware (formerly paid, now free)
- Price point (current): Free
- Platforms: Windows (32-bit and 64-bit)
- First released: 1990s (exact date unknown)
- Last meaningful update: v2.10.01 (date unspecified, 2024 or later)
- Source available: No (closed-source freeware)
- Primary use case: Pixel art animation for game sprites and character animation

## Origin and purpose

GraphicsGale is a long-running Windows pixel editor that served as paid software for decades before transitioning to freeware. Originally developed in Japan, the tool became a fixture in indie game and animation workflows. The shift to freeware removed licensing barriers, making it accessible to hobbyists and professionals globally. Despite the vintage UI and development pace, GraphicsGale maintains active use in pixel art communities due to its reliable animation tools and cel-based workflow familiar to traditional animators.

## Drawing and painting tools

GraphicsGale provides pencil, eraser, line, rectangle, and ellipse tools. Brush sizes and hardness are customizable. Fill tool enables bucket fill and gradient fill. Custom brushes are supported. Selection tools (rectangular, freehand) isolate regions. Color picker (eyedropper). The drawing toolkit is functional and responsive, with a focus on animation rather than advanced painting effects.

## Pixel-specific features

Grid overlay with configurable spacing and snapping. Zoom levels from close-up pixel work to full-sprite overview. Pixel-perfect line drawing prevents sub-pixel artifacts. Tiled drawing mode creates seamless patterns. Rotation and flip commands apply to selections and entire frames. Transparent canvas background option aids visibility of alpha channels. Customizable canvas size and composition.

## Color and palette workflow

Color swatches for quick foreground/background selection. Palette management with custom palette creation and import. Indexed color and RGB mode support. Color range selection for batch color changes. Palette-based workflows suit retro game art (NES, SNES, Sega palettes). Animated palette effects via color cycling. Eyedropper tool samples colors from the canvas.

## Layer system

Multiple layers support sprite composition with transparency. Layer toggling enables selective visibility during editing. Layers organize artwork components (outline, fill, effects). Merging layers combines them while flattening removes transparency. Layer opacity control (though not as granular as modern tools). The layer system is straightforward and suitable for traditional cel animation workflows.

## Animation features

Cel animation is the core strength. The timeline displays frames horizontally with multiple layers. Onion skinning (display of adjacent frames semi-transparently) enables smooth motion referencing. Onion skin range and opacity are adjustable. Real-time playback preview shows animation at specified frame rate and loop settings. Frame durations are editable. Multiple cels per frame (via layers) enable complex animations. Animation playback is responsive. Cel composition allows assembling animations from pre-drawn frames.

## Export and import

Animated GIF export is a freeware limitation; GIFs must be exported frame-by-frame as PNG sequences. PNG image export with transparency. AVI (video) export and import of AVI sequences. ICO (icon) and CUR (cursor) formats support. Import PNG images or sequences to populate frames. BMP and DIB support. The GIF limitation (no direct GIF save) is a quirk of the freeware license; workarounds involve third-party GIF assemblers.

## Scripting and extensibility

No scripting or plugin system. The tool is closed-source freeware without extensibility hooks. Customization requires waiting for developer updates or using external batch processing tools to complement GraphicsGale's output.

## Engine integration

GraphicsGale exports are compatible with game engines via PNG sequences and AVI video. Sprite sheets can be assembled from PNG exports using third-party tools. No native engine plugins or integration workflows. Manual sprite sheet composition is necessary.

## Workflow strengths

Reliable cel animation tools with responsive onion skinning. Keyboard shortcut customization accelerates workflows. Multiple animation playback options (loop, ping-pong, single frame). Palette-based indexed color workflows suit retro game art. Real-time animation preview with adjustable playback speed. Freeware status eliminates licensing costs. Windows 11/10 compatibility maintains modern OS support. Long development history means stable, battle-tested codebase.

## Workflow gaps

GIF export as freeware is removed; frame-by-frame PNG export and external assembly required. No direct sprite sheet generation; manual composition necessary. Limited advanced features (no text tool, no blend modes beyond basic overlay). No scripting or automation. UI is dated and not refreshed for modern design standards. No layer blend modes or advanced compositing. No non-destructive effects. Platform locked to Windows; no macOS or Linux versions. Documentation is sparse and tutorials are scarce. Development pace is slow; updates are infrequent.

## Notable uses

GraphicsGale remains popular in retro game communities and pixel art hobbyist circles. Game Boy and SNES-era sprite creation workflows benefit from its palette and cel tools. Character animators in small studios use it alongside modern tools. Animation education in some institutions teaches cel animation concepts using GraphicsGale due to familiarity and low cost.
