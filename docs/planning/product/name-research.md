If reconsidering any candidates:

All three strong candidates have solid open-source project potential with minimal legal/trademark friction.

## Recommendation

**Choose: Mosaica**

**Rationale:**
- GitHub org cleanly available (404)
- .io and .dev domains presumed available (whois.com security checks suggest no WHOIS data = available, but CAPTCHA prevented full verification)
- No existing prior-art products in pixel art / sprite editing / animation space
- Distinctive enough for clean search (mosaica pixel art, mosaica editor)
- Feminized variant memorable and unique without being silly
- Can register mosaica.io + mosaica.dev immediately; .com is taken but not critical for modern OSS

**Fallback: Pixhaus**
- Equally strong position (GitHub avail, modern TLDs likely open)
- Slightly more memorable than Mosaica but Bauhaus design association could be seen as derivative
- If Mosaica.io is unavailable, Pixhaus is the next best choice

**Do NOT pursue:**
- Pixelforge: .io locked for 3+ years
- Pixaria: Too vague/forgettable
- Spritery, Pixmint, Embergrid: GitHub claimed
- SpriteMaster: Project codename, conflicts with internal branding
